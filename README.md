# مجلس خلفان — khalfan-majlis

المكتب الافتراضي ثلاثي الأبعاد لـ «فريق خلفان»: ستيفن، مايكل، جنيفر، كرستينا، ماثيو.
فيه المجلس العُماني وغرفة الاجتماعات «قهوة المغرب».

- يشتغل على الماك والآيباد والآيفون من المتصفح (Safari / Chrome).
- مبني بـ Three.js في ملف واحد `index.html` بدون خادم، ومنشور على GitHub Pages.
- مشروع مستقل عن الأكاديمية.

## المراحل
1. ✅ الهيكل: المجلس، الشخصيات الخمس، التنقل، لوحة كل عضو، قهوة المغرب.
2. ⏳ قهوة المغرب والاستراحة: محاضر الاجتماعات، الأصوات.
3. ⏳ البيانات: `data.json` مشفّر بكلمة سر، اللوحات، الحالات، التثبيت كتطبيق (PWA).
4. ⏳ الصقل: شخصيات بنماذج مولّدة، حركات، إضاءة.

## تنبيه خصوصية
الموقع عام على GitHub Pages. لا تضع فيه أي بيانات حساسة (أرقام مالية، إيميلات، بيانات موردين، أو أي شيء عن جهة العمل) قبل تفعيل التشفير في المرحلة 3.
